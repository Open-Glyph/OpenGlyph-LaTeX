# 从图像检索到 JSON，再排进论文

LaTeX 宏包不识字，也不联网。可编辑字形由前置工具检索、选择或构造，然后把实际字体和名称映射交给 LaTeX。

## 图像工具（可选）

使用 guwenzi-tools 0.6+，先登录并以 `tools --server` 确认服务已部署模板接口。给已登记的单字图：

```sh
guwenzi-tools glyph templates ASSET_ID --scope all --output work/templates
guwenzi-tools glyph inspect --program @program.json --hint-asset ASSET_ID --output work/parts
guwenzi-tools glyph compose --program @edited.json --hint-asset ASSET_ID --output work/composed
```

program.json 来自实际候选，不凭记忆编造编号。scope=component 可检索已有命名部件和笔画组。排名不是身份概率；有原文嵌入字体时可以直接复用原轮廓。

Inspect 返回编号节点及按原图计算的局部修改候选。符合原图的候选可用 `glyph compose --proposal RETURNED_ID --hint-asset ASSET_ID --output work/composed` 选择。候选绑定原图，不能跨字套用。无合适候选时才编辑 JSON；任意缺失几何不能凭一个名称产生。

## 新部件也是 JSON 程序

`examples/modules.json` 定义一个“框内加点”的模块，并用它替换另一个字中的部件：

```sh
python scripts/openglyph.py build examples/modules.json -o module-font
```

然后 `\OpenGlyphLoad{module-font}`，正文写 `\gwglyph{modules:newform}`。模块可以引用同级其它模块，但不能循环。新增形体只是示例，不虚构出处或读音。

若要抽取底字里的若干记录，程序可以有：

```json
"select": {"parent":"root", "nodes":["r0","r1","r2","r3"]}
```

编号须先inspect对应版本；选择发生在edits之前，并保留原父层200单位字格，不把小部件自动拉伸成满格。带作用域变换的记录层拒绝抽取，不静默损坏结构。

## 接收远端成果

远端字体包包含真实 OTF、catalog.tex、sample.tex、映射和可用的 project.json。附带字体可以直接编译；修改项目时，用本版离线编译器重新build，再加载新目录。需要延续已有PUA槽位时传 --allocation；PUA只属于那份字体，不是全球字码。

远端新增部件可用 box="auto"，由原图驱动求位置；这是前置图像工具的能力，不是LaTeX编译期功能。离线构建使用服务返回的已解析整数框，不能把未解析auto当成无图也能计算的指令。

最终检查实际文档字体与原形，保留差异并交给研究者确认。文件生成、DINO高分、像素相似都不等于学术身份确认；主文用字体文字，原图对照另附。
